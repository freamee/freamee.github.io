Inventory 4.0

A modern inventory system with responsive item management, integrated shops, flexible storage, character equipment and extensive server APIs.

Features​

Player experience

Inventory interaction

Integrated shops

Purchase registered items directly through shops built into the inventory system.

Fast drag and drop

Move items smoothly between slots, storage containers and other open inventories.

Action slots

Assign items to shortcut slots one through five for quick use during gameplay.

Tooltips and organization

Add notes, rename items and use detailed tooltips to keep important belongings organized.

Customizable interface

Adjust colors and other visual settings to match the player's preferences or your server style.

Shareable settings

Export a preferred interface setup and share it with other players.

Character systems

Equipment and player interaction

Character model integration

Reflect equipped clothing and supported items directly on the active character model.

Clothing management

Equip, remove and switch clothing variations through a familiar dp-clothing-style workflow.

Weapon attachments

Install and manage supported weapon attachments as part of the inventory experience.

Player frisking

Inspect a target player and interact with the items in their inventory.

Inventory systems

Storage and item framework

World item drops

Place items in the world using a different object model configured for each item.

Temporary and permanent stashes

Create persistent storage or temporary stashes that disappear without saving their contents to SQL.

External inventories

Connect vehicle trunks, gloveboxes, faction safes, group storage and other inventory types.

Flexible item registration

Define custom items and connect the behavior required by your other server resources.

Item metadata

Store durability and other custom attributes on individual item instances.

FiveM RPC

Exports

Register and trigger events, create RPC listeners and call them between server, client and browser environments.

Server and client​

API reference

Adding events

Register individual or grouped local and global events.

4 exports
NameDescriptionParametersReturns
exports["fivem-rpc"]:on(eventName, cb)

Adds a single local event.

eventNamestringcbEventCallback
—
exports["fivem-rpc"]:onGlobal(eventName, cb)

Adds a single global event.

eventNamestringcbEventCallback
—
exports["fivem-rpc"]:onMany(e)

Adds multiple local events from a key-value table.

eRecord<string, EventCallback>
—
exports["fivem-rpc"]:onGlobalMany(e)

Adds multiple global events from a key-value table.

eRecord<string, EventCallback>
—

Examples​

  • on
  • onGlobal
  • onMany
  • onGlobalMany
Configuration

on

Local event example.

exports['fivem-rpc']:on('onPlayerLogin', function(playerSource)
    print(playerSource)
end)
Configuration

onGlobal

Global event example.

exports['fivem-rpc']:onGlobal('onPlayerLogin', function(playerSource)
    print(playerSource)
end)
Configuration

onMany

Multiple local events example.

exports['fivem-rpc']:onMany({
    ['onPlayerLogin'] = function(playerSource)
        print(playerSource)
    end,
    ['onPlayerLogout'] = function(playerSource)
        print(playerSource)
    end
})
Configuration

onGlobalMany

Multiple global events example.

exports['fivem-rpc']:onGlobalMany({
    ['onPlayerLogin'] = function(playerSource)
        print(playerSource)
    end,
    ['onPlayerLogout'] = function(playerSource)
        print(playerSource)
    end
})

Configuration

Register the listener

Register the listener on the client.

Register a client-side listener
exports["fivem-rpc"]:register("isPlayerSwimming", function()
    return IsPedSwimming(PlayerPedId())
end)
Configuration

Call the listener

Call the event from the server.

Calling the event from server
local isSwimming = exports["fivem-rpc"]:callClient(source, "isPlayerSwimming")
print(isSwimming)
Configuration

Register the global listener

Register the listener on the client.

Register a client-side listener
exports["fivem-rpc"]:registerGlobal("isPlayerSwimming", function()
    return IsPedSwimming(PlayerPedId())
end)
Configuration

Call the global listener

Call the event from the server.

Calling the event from server
local isSwimming = exports["fivem-rpc"]:callGlobalClient(source, "isPlayerSwimming")
print(isSwimming)

Import the browser.js or browser.ts file into your frontend.

Browser RPC functions

Global event and listener functions available in the browser environment.

- triggerGlobalServer(eventName: string, args?: any)
- triggerGlobalClient(eventName: string, args?: any)
- callGlobalServer<T>(eventName: string, args?:any): Promise<T>
- callGlobalClient<T>(eventName: string, args?:any): Promise<T>
